# 宝可梦 · 弹珠研究所

手机触屏单人弹珠探索游戏，纯静态网页，无需账号、后端或依赖安装。

## 连续探索版 v3.0

- 打开页面立即投球，多颗小精灵球同时在密集钉阵中下落、碰撞。城镇水道背景、红白转环和底部收集口参考用户提供的游戏录像重新绘制。
- 只有自动投球开关会暂停游戏：关闭后冻结所有球，打开后继续。捕获、图鉴和扭蛋均不暂停探索，没有「收入图鉴」确认弹窗。
- 不再消耗能量，不会因为旧存档能量为零停机。0.5×–5× 速率可调并保存；每次重新进入默认自动开始。
- 1× 下每 0.65 秒投一球。速率同时调整发射频率和运动速度；高倍率会使场上球更密集。最多 48 球，固定 120 Hz 物理步进。
- 重力下落、错位钉阵反弹、转环实物碰撞、收集口导轨。穿过转环中心提升稀有和闪光机遇。录像没有提供物理参数，数值为视觉近似，不是原游戏的精确复刻。
- 30 种伙伴，自动捕获、个人图鉴、重复数量、闪光收藏。精灵扭蛋花费 50 金币，闪光概率 5%；探索闪光概率由基础 5% 随幸运加成提升，最高 12%。
- 手机切到后台时暂停计算，返回后自动接着运行；切换游戏内页签不会暂停。
- 保留旧版 `pocket-field-v1` 本地存档。自动保存到当前浏览器，支持 JSON 导入导出；不同设备和浏览器不会自动同步。定期导出备份，清除浏览器数据会丢失进度。

## 手机发布

代码放在 GitHub 仓库 `JustinZheng0518/Pokemon` 的 `main` 分支。

1. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
2. **Actions → Deploy GitHub Pages** 必须显示成功。每次推送会自动重新部署；首次启用 Pages 后可使用 **Run workflow**。
3. 手机打开 `https://justinzheng0518.github.io/Pokemon/`。网址只有发布成功后才可用。

iPhone 可在 Safari「分享 → 添加到主屏幕」，Android 可使用浏览器菜单的「添加到主屏幕」。如果仍看到需要「收入图鉴」的旧弹窗，请刷新页面，确认页头显示 **v3.0**；CSS 和脚本已使用新的版本地址避免旧缓存。

## 本地运行

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

从仓库目录运行。没有安装或构建步骤。所有游戏资源随站点发布，无需 Google Fonts 或运行时访问第三方图片服务器；不包含服务工作线程或离线缓存。
