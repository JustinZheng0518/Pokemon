# 口袋探险 · 弹珠研究所

为手机触屏设计的单人宝可梦同人小游戏。无需账号、后端或付费 API。

- 调整方向、发射弹珠，碰撞获得金币，每轮必遇一只宝可梦。
- 30 种伙伴、稀有伙伴及 5% 闪光概率；重复捕获计入收藏。
- 50 金币开启扭蛋，30 金币补充 5 点能量；每日能量补足至至少 20。
- 自动保存在当前浏览器，支持 JSON 导入和导出。不同设备、浏览器之间不会自动同步，请定期导出备份。

## 在手机上玩

将本目录上传到 GitHub 仓库 `JustinZheng0518/Pokemon` 的 `main` 分支。在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。推送代码后，等待 **Actions → Deploy GitHub Pages** 成功。

发布成功后，使用手机浏览器打开 `https://justinzheng0518.github.io/Pokemon/`。iPhone 可使用 Safari「分享 → 添加到主屏幕」，Android 可在浏览器菜单选择「添加到主屏幕」。不需要安装 App。该地址只有部署成功后才可用。

## 本地运行

在现有仓库目录运行（无需安装依赖）：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

在本机访问服务器即可。没有构建步骤。不要直接用文件管理器打开 HTML，以免浏览器本地存储策略造成差异。

宝可梦精灵图来自 PokeAPI/sprites 的 GitHub 公共资源，字体来自 Google Fonts；网络不可用时会回退到精灵球图标和系统字体，游戏逻辑与本地存档仍可运行。不包含离线缓存。
